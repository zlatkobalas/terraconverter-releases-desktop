# TerraConverter Desktop — Releases

Download-only repository for the **TerraConverter desktop GUI**, a coordinate-conversion tool between Croatian and global coordinate systems (WGS84, HDKS, MGI 1901, HTRS96/TM, UTM/UPS, MGRS, ECEF, Plus Code, Geohash).
This repository contains **no source code** — only compiled builds, published under [Releases](../../releases). The application is closed-source freeware for non-commercial use; see [`LICENSE.md`](LICENSE.md) (English, canonical) or [`LICENSE.hr.md`](LICENSE.hr.md) (Croatian).

Looking for the command-line version or the Android app instead? See
[terraconverter-releases-cli](https://github.com/zlatkobalas/terraconverter-releases-cli)
or [terraconverter-releases-android](https://github.com/zlatkobalas/terraconverter-releases-android).

## Downloads

- **Windows — Installer** (`TerraConverter-vX.Y.Z-setup.exe`) — recommended for most users. Guided setup, Start Menu shortcut, clean uninstall via Windows "Apps & features".
- **Windows — Portable** (`.zip`) — no installation, no admin rights, no registry changes. Extract anywhere and run `TerraConverter.exe` directly; useful for USB drives or restricted machines.

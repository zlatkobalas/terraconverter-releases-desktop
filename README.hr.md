# TerraConverter Desktop — Izdanja

Repozitorij isključivo za preuzimanje **TerraConverter desktop GUI-ja**, alata za pretvorbu koordinata između hrvatskih i globalnih koordinatnih sustava (WGS84, HDKS, MGI 1901, HTRS96/TM, UTM/UPS, MGRS, ECEF, Plus Code, Geohash).
Ovaj repozitorij **ne sadrži izvorni kod** — samo gotove izgradnje, objavljene pod [Releases](../../releases). Aplikacija je zatvoreni freeware za nekomercijalnu upotrebu; vidi [`LICENSE.hr.md`](LICENSE.hr.md) (hrvatski prijevod) ili [`LICENSE.md`](LICENSE.md) (engleski, mjerodavan).

Tražiš naredbeno-rednu (CLI) ili Android verziju? Vidi
[terraconverter-releases-cli](https://github.com/zlatkobalas/terraconverter-releases-cli)
ili [terraconverter-releases](https://github.com/zlatkobalas/terraconverter-releases).

## Preuzimanja

- **Windows — Installer** (`TerraConverter_Setup_vX.Y.Z.exe`) — preporučeno za većinu korisnika. Vođena instalacija, prečac u izborniku Start, uredna deinstalacija preko Windows "Aplikacije i značajke".
- **Windows — Portable** (`.zip`) — bez instalacije, bez admin prava, bez zadiranja u registry. Raspakiraj bilo gdje i pokreni `TerraConverter.exe` izravno; korisno za USB diskove ili ograničena računala.
